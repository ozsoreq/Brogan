# אקדמיית הלמידה

אפליקציית לימוד ומשחקים לילדים, בנויה עם React + TypeScript + Vite.

## מה יש כאן

- **מסך בית** – בחירה בין "למידה" ל"משחקים".
- **למידה** – רשימת מודולי למידה, כרגע כולל את המשחק "השלם את המילה"
  (שני מודולים נוספים מוצגים כ"בקרוב").
- **השלם את המילה** – סדרה של 10 מילים בעברית עם אות חסרה. הילד/ה בוחר/ת
  את האות הנכונה מתוך 10 אפשרויות, מקבל/ת משוב מיידי (✓/✗) ובסיום
  מוצג ציון סופי בין 0 ל-100.
- **משחקים** – מסך placeholder, יתמלא במשחקים נוספים בהמשך.

## פיתוח

```bash
npm install
npm run dev
```

## טכנולוגיות

- React + TypeScript + Vite
- React Router
- Tailwind CSS
- Framer Motion
- lucide-react (אייקונים)
