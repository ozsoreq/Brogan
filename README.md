# אקדמיית הלמידה

אפליקציית לימוד ומשחקים לילדים, בנויה עם React + TypeScript + Vite.

## מודולים

- **השלם את המילה** – 10 מילים אקראיות מתוך מאגר של 500+ מילים, לכל מילה אימוג׳י
  ייחודי כרמז. בוחרים את האות החסרה מתוך 10 אותיות, ובסוף מקבלים ציון מתוך 100.
- **חשבון** – 50 שלבים של 10 תרגילים. חיבור וחיסור מההתחלה, כפל משלב 10, חילוק
  משלב 15. צריך 10/10 כדי לפתוח את השלב הבא.
- **עברית (הבנת הנקרא)** – 50 סיפורים לכיתות א׳-ב׳ עם שאלות אמריקאיות. הסיפור נשאר
  על המסך בזמן המענה. צריך לענות נכון על כל השאלות כדי לעבור שלב.
- **משחק הזיכרון** – הופכים שני קלפים ומוצאים זוגות. 3 רמות (6/8/10 זוגות) לכיתות
  א׳-ד׳, כוכבים לפי מספר המהלכים ושיא אישי לכל רמה.
- **תפסו את האוגר!** – משחק תגובה של 30 שניות: נוגעים באוגר כשהוא יוצא מהגומה. ברמות
  בינוני/קשה מופיעות גם פצצות שאסור לגעת בהן (מינוס 2). כוכבים ושיא אישי לכל רמה.
- **רוץ, דינו, רוץ!** – משחק ריצה בנגיעה אחת: הדמות רצה לבד, נוגעים כדי לקפוץ מעל
  קקטוסים וסלעים ולתפוס כוכבים. המהירות עולה בהדרגה. בוחרים אחת מ-6 דמויות, ויש שיא אישי.
- **חותכים פירות!** – מחליקים את האצבע (או נוגעים) על פירות שעפים באוויר וחותכים אותם לשניים.
  3 פירות בהחלקה אחת = בונוס 🔥. סבב של 60 שניות עם 3 לבבות; פצצה מורידה לב, וברמות
  בינוני/קשה גם פרי שנופל. 3 רמות לכיתות א׳-ד׳ ושיא אישי לכל רמה.
- **הנחש הרעב** – מכוונים נחש (החלקה על הלוח או כפתורי חצים גדולים) לאכול תפוחים 🍎; כל תפוח מאריך
  אותו, וכל 5 תפוחים מופיע כוכב בונוס ⭐ (3 נקודות). קל: לוח קטן ואיטי בלי קירות; בינוני: מאיץ;
  קשה: מהיר עם קירות מסוכנים. 3 רמות לכיתות א׳-ד׳ ושיא אישי לכל רמה.
- **שוברים לבנים!** – גוררים מחבט ומקפיצים כדור כדי לשבור קיר של לבנים צבעוניות 🧱. לבנה עם כוכב
  מפילה כוכב ⭐ שאפשר לתפוס במחבט (3 נקודות); ניקוי הקיר = בונוס ושלב חדש בצורה אחרת ומהיר יותר.
  קל: מחבט רחב ו-5 לבבות; בינוני: יותר לבנים; קשה: מהיר עם לבני ברזל שצריך לפגוע בהן פעמיים.
- **בונים מגדל!** – בלוק זז מצד לצד, ונגיעה במסך מפילה אותו על המגדל 🏗️. מה שבולט נחתך ונופל, כך שהמגדל
  נהיה צר יותר; הנחה מושלמת ✨ שווה 2 נקודות, ורצף של מושלמות מרחיב אותו בחזרה. השמיים משתנים עם הגובה
  (יום, שקיעה, לילה בחלל). קל: איטי ורחב; בינוני: מאיץ; קשה: מהיר וצר. שיא אישי לכל רמה.
- **ארבע בשורה** – משחק חשיבה בתורות מול המחשב: מפילים דיסקיות אדומות 🔴 והמחשב צהובות 🟡, ומי שמסדר
  ראשון ארבע ברצף (לרוחב, לגובה או באלכסון) מנצח. קל: המחשב לפעמים מפספס; בינוני: תמיד חוסם ולוקח
  ניצחון; קשה: מחשב שמתכנן כמה מהלכים קדימה. התור הראשון מתחלף, וטבלת ניצחונות נשמרת לכל רמה.
- **העכבר במבוך** – עוזרים לעכבר 🐭 להגיע לגבינה 🧀 במבוך שנוצר מחדש בכל משחק. מחליקים על המבוך או לוחצים
  על החצים, והעכבר רץ לאורך המסדרון עד הפנייה הבאה ומשאיר שביל. 5 שלבים שגדלים, כוכבים ⭐ לאסוף בדרך,
  וכפתור רמז 💡 שמראה את הדרך (+5 שניות). קל: 5×5 עד 8×8; בינוני: עד 11×11; קשה: עד 14×14. זמן שיא לכל רמה.
- **זוכרים את הרצף** – חיות נדלקות אחת אחרי השנייה 🐶🐸🐱🐵, כל אחת עם צליל משלה 🎵, וצריך ללחוץ עליהן
  באותו סדר. בכל סבב הרצף מתארך בעוד חיה; טעות מנגנת שוב את אותו רצף כל עוד נשארו לבבות. קל: 4 חיות,
  לאט, 3 לבבות; בינוני: מהר יותר, 2 לבבות; קשה: 6 חיות, מהיר, לב אחד. שיא (הרצף הארוך ביותר) לכל רמה.
- **מצאו את השונה** – לוח מלא בתמונות זהות, ורק אחת שונה 🔍. מוצאים ולוחצים מהר; כל מציאה מביאה לוח חדש,
  וכל 3 מציאות הלוח גדל. 60 שניות, לחיצה לא נכונה עולה בשניות. קל: תמונות שונות מאוד ורמז (התמונה השונה
  מתנדנדת אחרי 5 שניות); בינוני: תמונות דומות (🍎/🍅); קשה: כמעט זהות (😀/😃) בלוח של עד 7×7. שיא לכל רמה.

ההתקדמות בשלבים נשמרת בדפדפן (localStorage) וניתנת לאיפוס ממסך בחירת השלב.

בכל המסכים: צלילים והקראה בקול בעברית (כפתור 🔊/🔇 בכותרת), ניקוד בשלבי העברית 1-20,
השהיה ⏸ במשחקי הזריזות, ומסך "סובבו את הטלפון" כשמחזיקים את הטלפון לרוחב.

## פיתוח

```bash
npm install
npm run dev      # שרת פיתוח
npm test         # בדיקות אוטומטיות (Vitest)
npm run lint     # oxlint
npm run build    # בנייה לפרודקשן (dist/)
```

## פריסה

הפרויקט מוכן ל-Vercel: `vercel.json` מפנה כל נתיב ל-`index.html` כך שרענון של
כתובת פנימית (למשל `/learning/math/3`) לא יחזיר 404.

האפליקציה היא PWA: אחרי הפריסה, פותחים את הכתובת בטלפון ובוחרים "הוספה למסך הבית"
(ב-iPhone: כפתור השיתוף ← "הוספה למסך הבית"). היא נפתחת במסך מלא עם אייקון משלה,
ועובדת גם בלי אינטרנט אחרי הביקור הראשון (`sw.js` נוצר בבנייה מ-`sw-template.js`).

## מבנה

- `src/lib/useQuizSession.ts` – זרימת שאלה→משוב→מעבר, משותפת לכל המשחקים
- `src/lib/useLevelProgress.ts` – נעילת/פתיחת שלבים ושמירה ב-localStorage
- `src/components/` – רכיבים משותפים (כותרת, רשת שלבים, מסך תוצאה, משוב ✓/✗)
- `src/games/<module>/` – תוכן ולוגיקה של כל מודול, עם קובץ `*.test.ts` לצידו
